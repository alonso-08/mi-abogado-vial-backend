# Asistente Legal Vial - Backend API

API para el asistente legal vial de Mexico.

## Setup

```bash
# Instalar dependencias
poetry install

# Activar entorno virtual
poetry shell

# Ejecutar servidor
poetry run uvicorn app.main:app --reload
```

## Variables de entorno

Copia `.env.example` a `.env` y configura las variables.

## API Docs

Una vez ejecutado, visita: http://localhost:8000/docs
